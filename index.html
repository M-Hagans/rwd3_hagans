Reflection

Before this assignment, I never understood how responsive typography worked or why it mattered. I always used basic pixel sizes, which stay the same no matter what screen you’re on. Learning the clamp function showed me how text can have a minimum size, a flexible size, and a maximum size all at once. This made my heading change smoothly as the screen got bigger or smaller, instead of jumping or looking too big. I also learned how spacing, layout, and simple comments in my CSS make everything easier to read and adjust. Overall, this assignment helped me see how important good typography is for making a webpage look clean, readable, and professional on any device.
